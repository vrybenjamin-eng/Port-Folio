Mon Portfolio 

Mon portfolio est fais en python
Un clic sur un projet ouvre une page avec ses détails.
le site comporte
- Introduction
- Projets (avec une page par projet)
- CV
- Contact


Le site se lance avec:
   py app.py dans le terminal
   Ouvrir http://127.0.0.1:5000 dans le navigateur.
   Pour arrêter le site : `Ctrl + C` dans le terminal.

Les dossiers

app.py            -> le programme qui fait marcher le site
projets.py        -> TOUTES mes infos (c'est le seul fichier à modifier)
requirements.txt  -> la liste de ce qu'il faut installer
templates/        -> les pages HTML (ne pas toucher)
static/           -> mes images, vidéos, CV et le style (css)


Les modifications se fonts dans projets.py
